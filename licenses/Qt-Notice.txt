Replaceability (LGPLv3 section 4(d)(1))
---------------------------------------
  The ready-made Windows build is a single-file executable: the Qt libraries are
  packed inside it and unpacked to a temporary directory at run time, so end
  users cannot replace those libraries in place. That is why the source
  availability above is the mechanism used to satisfy section 4(d). To produce a
  build whose Qt libraries sit in a normal folder and can be swapped, build with
  `XSY_ONEDIR=1` (see `packaging/xiangshuiyin-qt.spec`).
