# 跨平台功能点差异

**文档性质**：本文说明本项目在不同操作系统上存在差异的功能点、差异成因及其影响，供使用者评估与开发者适配参考，不涉及开发计划。

**总体情况**：水印渲染、图像导出、参数与预设管理等核心能力在 Windows、macOS 与 Linux 上结果一致；界面字体与图标素材随程序分发，不依赖系统资源。差异集中在安装方式、少数与窗口系统相关的交互功能以及系统集成细节上，按影响程度分级如下。Windows 为当前主要验证平台，标注为「预期」的条目尚未在对应平台完成实测。

## 影响等级

| 等级 | 判定标准 |
|---|---|
| 高 | 该平台缺少完成主要工作流所必需的能力，或无法直接安装运行，需改用其它方式 |
| 中 | 某项功能在该平台不可用或行为不同，核心流程不受影响，可通过其它方式达到同一目的 |
| 低 | 仅为界面外观、系统集成方式或边缘场景的差异，不影响任何操作结果 |

## 一、高影响

| 功能点 | Windows | macOS | Linux | 原理 | 影响 |
|---|---|---|---|---|---|
| 安装与运行方式 | 提供安装器（单文件，装出程序目录），无需额外运行环境 | 需自备 Python 运行环境并从源码启动（预期） | 需自备 Python 运行环境并从源码启动（预期） | 构建产物按平台生成且不可交叉生成。Windows 已提供安装器产物（内含目录形态的程序本体）；macOS 的应用包需要额外的清单文件与代码签名，未签名或未公证时会被系统拦截；Linux 的桌面集成文件尚未提供。 | 非 Windows 用户无法直接双击运行，需具备命令行操作能力；部署与分发的成本相应增加 |
| 运行架构覆盖 | x86-64 已支持 | x86-64 与 Apple 芯片预期支持 | x86-64 已提供依赖；ARM 架构是否提供尚未确认 | 运行时依赖以平台专用二进制包分发：Windows 的 x86-64、macOS 的 x86-64 与 Apple 芯片、Linux 的 x86-64 均有对应包，Linux ARM 架构的对应包尚未确认；缺失时需从源码构建 Qt 绑定。 | 采用 ARM 架构的 Linux 设备需要自行构建依赖，否则无法运行 |

## 二、中影响

| 功能点 | Windows | macOS | Linux（X11） | Linux（Wayland） | 原理 | 影响 |
|---|---|---|---|---|---|---|
| 参数行的间距悬停高亮 | 可用 | 可用（预期） | 可用 | 受限，可能不生效 | 该功能按屏幕全局光标坐标判断光标落在哪个参数行：定时读取光标位置，再换算为窗口内的控件坐标。Wayland 协议不向客户端提供全局光标位置，该值只能由鼠标移动事件推算，X11、macOS 与 Windows 的窗口系统则提供这一信息。 | 在 Wayland 会话中，将光标停留在参数行上可能不会在预览图中标出对应的间距区域，放大镜同样可能不出现；用户需依据参数名称与数值判断对应关系。图像渲染与导出不受影响 |

## 三、低影响

| 功能点 | Windows | macOS | Linux | 原理 | 影响 |
|---|---|---|---|---|---|
| 重复启动时的窗口置前 | 第二个进程将已有窗口置于最前 | 通常仅在程序坞中提示 | 通常仅在任务栏中提示 | 防重复启动依靠本地套接字实现，各平台一致。窗口置前取决于窗口系统的激活策略：Windows 提供直接置前的系统调用，并允许后启动的进程先行放开权限；macOS 与 Linux 需要各自的桌面环境接口，本项目未接入，只发出通用的激活请求，是否被采纳由桌面环境决定。 | 重复启动不会产生第二个进程，也不会重复写入配置；仅窗口不一定会自动出现在最前方，需用户自行切换 |
| 窗口与任务栏图标 | 使用随程序分发的图标 | 跟随分发形态，尚未提供 | X11 会话预期生效；Wayland 会话下窗口图标由桌面条目文件提供，程序自行设置不生效 | 程序图标使用 Windows 图标格式，并通过通用接口设置。Wayland 协议不提供窗口级图标的设置能力，图标由桌面条目文件声明；macOS 以应用包声明其专用图标格式。 | Wayland 桌面中任务栏可能显示为默认图标；不影响任何功能 |
| 系统原生文件选择界面 | 由操作系统绘制，外观与文案随系统语言 | 由操作系统绘制，外观与文案随系统语言 | 由 Qt 绘制或跟随桌面环境，外观与列名语言可能与桌面其它程序略有差异 | 实现上优先使用操作系统原生的文件选择界面，桌面环境未提供对应集成时由 Qt 绘制。Qt 绘制部分的按钮与列名取自 Qt 自带的翻译目录，按程序界面语言装载，因此其语言不一定与系统语言一致。 | 仅为界面外观与文案差异，不影响文件的选择结果 |
